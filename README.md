# Электронная торговая сеть - Django REST API
## Описание проекта
Проект представляет собой веб-приложение для управления сетью поставщиков электроники с иерархической структурой. 

Реализованы:
- Трехуровневая система поставщиков (заводы, розничные сети, ИП)
- Управление контактной информацией и продуктами
- Контроль задолженности между поставщиками
- REST API с JWT-аутентификацией
- Административный интерфейс Django

## Технологический стек
- Python 3.8+
- Django 3.2+
- Django REST Framework 3.12+
- PostgreSQL 10+
- SimpleJWT для аутентификации
- Django Filter для фильтрации
- drf-yasg для документации API

## Установка и запуск
Клонировать репозиторий:
```git clone https://github.com/Natalia-Epifanova/Electronics_network```

```cd Electronics_network```

Создать и активировать виртуальное окружение:

```python -m venv venv```

```source venv/bin/activate```  # Linux/MacOS

```venv\Scripts\activate```     # Windows

Установить зависимости:

```pip install -r requirements.txt```

Настройка базы данных (PostgreSQL):
- Создать БД
- Создать ```.env``` файл и заполнить аналогично ```.env.example```

Применить миграции:

```python manage.py migrate```

Создать суперпользователя:

```python manage.py csu```

Запустить сервер:

```python manage.py runserver```

## Структура API
Аутентификация:

```POST /users/register/``` - Регистрация нового пользователя

```POST /users/login/```- Получение JWT-токена

```POST /users/token/refresh/``` - Обновление токена

```GET /users/profile/<int:pk>/``` - Просмотр профиля пользователя

Поставщики: 

```GET /suppliers/supplier/``` - Список поставщиков

```POST /suppliers/supplier/``` - Создание поставщика

```GET /suppliers/supplier/<id>/``` - Детали поставщика

```PUT/PATCH /suppliers/supplier/<id>/``` - Обновление поставщика

```DELETE /suppliers/supplier/<id>/``` - Удаление поставщика

Фильтрация:

По стране: ```?contact__country=<страна>```

По городу: ```?contact__city=<город>```

По типу: ```?type=<0|1|2>```

Продукты и контакты:

Аналогичные CRUD эндпоинты для ```/suppliers/product/``` и ```/suppliers/contact/```

## Административный интерфейс
Доступен по адресу /admin/ после создания суперпользователя.

Особенности:
- Отображение иерархии поставщиков
- Фильтрация по стране и городу
- Обнуление задолженности
- Ссылки на связанных поставщиков

## Тестовые данные
Проект включает фикстуры с тестовыми данными:
- ```contacts_fixture.json``` - контактная информация
- ```products_fixture.json```- продукты электроники
- ```suppliers_fixture.json``` - поставщики с иерархией

Для загрузки:

```python manage.py loaddata contacts_fixture.json products_fixture.json suppliers_fixture.json```

## Документация API
Документация в формате Swagger доступна после запуска сервера по адресу:

```/swagger/``` - Интерактивная документация

```/redoc/```- Альтернативная версия документации


## Особенности реализации
Иерархия поставщиков:
- Заводы (уровень 0)
- Розничные сети (уровень 1)
- ИП (уровень 2)
- Автоматический расчет уровня через свойство level

- JWT-аутентификация
- Запрет изменения задолженности через API
- Доступ только для активных пользователей
